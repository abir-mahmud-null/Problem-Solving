# Watermelon

**Platform:** Codeforces  
**Problem:** [Watermelon](https://codeforces.com/problemset/problem/4/A)  
**Rating:** 800  
**Language:** C++

## Approach

If the weight is even and greater than 2,
it can be divided into two positive even numbers.

So:

- n % 2 == 0
- n > 2

## Complexity

Time: O(1)  
Space: O(1)
